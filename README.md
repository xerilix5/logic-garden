# 🌿 Логический сад

Браузерная головоломка: 12 сбалансированных уровней, сенсорное управление, клавиатура и сохранения. Игра работает офлайн, без сервера, установки и сторонних библиотек.

## Запуск

Откройте `index.html` в современном браузере. Весь исходный JavaScript, CSS и интерфейс находятся в этом файле, сборка не нужна.

При желании запустите `python -m http.server 8000` из папки проекта и откройте http://localhost:8000.

## Правила и управление

Выберите шарик, затем его соседа. Соберите связную группу из 3+ одинаковых шариков, соединённых сторонами. Подходят линии и уголки. Неудачный обмен не расходует ход.

**Один обмен — одна волна удаления и одно начисление.** Заполнение не запускает цепные взрывы. Золотой шарик удваивает очки группы; группы из 4–5 выгоднее обычных троек. Если доступных ходов нет, поле обновляется бесплатно.

Стрелки — перемещение, Enter/пробел — выбор, Escape — отмена/пауза/возврат. Номер уровня открывает карту, кнопка паузы — громкость. Подсказка появляется через 20 секунд бездействия.

## Баланс

| Уровень | Типов | Цель | Ходов |
|---|---|---|---|
| 1 | 4 | 900 | 22 |
| 2 | 4 | 1050 | 24 |
| 3 | 4 | 1200 | 24 |
| 4 | 4 | 1300 | 24 |
| 5 | 5 | 1350 | 28 |
| 6 | 5 | 1400 | 28 |
| 7 | 5 | 1450 | 28 |
| 8 | 5 | 1500 | 28 |
| 9 | 6 | 1550 | 34 |
| 10 | 6 | 1600 | 34 |
| 11 | 6 | 1650 | 34 |
| 12 | 6 | 1700 | 34 |

Цель растёт на каждом уровне. При появлении новых типов на 5-м и 9-м добавляются ходы, чтобы избежать резкого скачка сложности.

Меняйте параметры в `levels.json`, затем выполняйте `npm run balance:apply`. При несовместимом изменении увеличьте `BALANCE_VERSION` в `index.html`, чтобы не загружать сессию со старыми ограничениями.

## Сохранения

Поле, очки, ходы, открытые/пройденные уровни, рекорды и громкость хранятся в localStorage. Серверу эти данные не отправляются. Сохранения привязаны к браузеру и адресу открытия игры. При обновлении старого баланса незавершённый уровень начинается заново, открытые уровни сохраняются.

## Тесты

Для разработки нужен Node.js 20+:

```bash
npm install
npx playwright install chromium
npm test
```

Эти зависимости нужны только для тестов, не для игры. Можно задать системный браузер через `CHROMIUM_PATH`. Результаты и скриншоты пишутся в `test-output/`, исключённый из Git.

Проверяются генерация 450 полей, допустимые обмены, завершение ходов, отсутствие каскадов на 120 обменах, пауза/перезапуск/смена уровня, сохранения, клавиатура и мобильные координаты.

```bash
npm run balance:simulate
```

Симулятор использует производственные функции игры и фиксированное зерно. 900 партий по 34 хода для 4–6 типов и трёх стратегий: случайный ход, выбор из лучшей трети по немедленным очкам и максимальное начисление без планирования наперёд. Сводка предыдущего прогона — `balance-evidence.json`.

Симуляции — не гарантия победы на каждом поле и не тестирование на реальных игроках. Поздние уровни могут потребовать повторных попыток.

## GitHub Pages

Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**. GitHub покажет игровую ссылку после успешного развёртывания. Наличие репозитория само по себе не означает, что Pages включён.
